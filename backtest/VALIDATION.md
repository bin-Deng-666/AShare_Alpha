# 回测验证

公开验证使用合成数据和测试专用策略 fixture，不包含真实行情、其他研究策略或模型产物。唯一应用示例为单标的买入并持有 demo。

统一运行：

```bash
ashare-alpha check --quiet
pytest -q
```

回测层的 45 项测试覆盖：

- 次日开盘、T+1、有效期、含费预算与部分成交。
- 真实股数、FIFO 成本、现金/权益恒等式和多批次标签。
- 普通板、科创板/CDR、北交所数量规则及零股退出。
- 停牌、未知交易状态、价格边界、不利触板、缺行情与 stale 估值。
- 公司行为应收与结算、成本守恒、缺失日期及不支持权益失败。
- 目标与订单模式、拒单、撤单、客户端去重和结束未完成订单。
- 时点视图、未来信息、只读快照、预热、参数和运行隔离。
- 基准缺口、初始资金回撤、无交易统计及输入指纹重放。
- 可得时刻现金利率、自然日计息、缺失标记及分类类型往返。

Demo 另验证：只买选定代码、价格下跌不卖出、停牌不生成交易、参数拒绝未知键，以及真实日计划从初始买入切换为持仓后无买卖。

离线演示可从安装包独立运行：

```bash
ashare-alpha demo --output /tmp/hold-demo
```

使用合成日历和行情生成一次买入及持续持有记录。测试不能证明实盘成交、未来收益或完整历史 PIT 数据；真实供应商质量通过独立的数据验收判断。精确重现保存实际输入和声明的代码依赖，查询库自身不构成数据快照。
