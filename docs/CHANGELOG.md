## 0.1.0

- 独立数据任务、审计与更新恢复；共享策略类回测、真实订单和模型账户。
- 单标的买入并持有 demo 的下一交易日计划与简化 WebUI。
- 安装包、统一命令、依赖组和 uv.lock；工作区可从源码目录分离。
- 服务退出终止任务进程组并持久化 interrupted 状态。
- 日计划使用不可变版本及原子提交索引，写入失败保留当前完整计划。
- 所有活跃日期入口取消工作日猜测，查询必须经过审计与共享读锁。
- 快照、结果和日计划格式版本；严格请求/配置验证。
- 完整测试入口、离线样例、CI、浏览器回归、架构和文档检查。

公开发布只包含框架、数据拉取代码和 demo，数据资产、模型、其他研究策略与旧实验历史保留本地。旧数据格式兼容读取；发布分支不携带旧研究提交。
