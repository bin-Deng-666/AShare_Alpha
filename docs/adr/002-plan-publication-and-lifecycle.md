# ADR 002：计划发布与任务生命周期

状态：采纳。

一份日计划的订单、持仓、信号日、执行日和输入身份必须一致。逐个覆盖 CSV、报告与 JSON 会使失败的生成留下混合结果，因此新计划写入 `plans/.revisions/<date>/<content_id>/`，完成所有文件后原子更新 `plans/index.json`。索引同时提交按日期的历史版本和当前计划。未提交目录不可见，同一天重新生成不会覆盖旧版本。

策略 `daily()` 只计算计划；公开命令完成报告发布。WebUI 的当前持仓、最新计划和历史计划共同读取提交索引。没有索引时兼容旧日期目录与旧 `plan.json`。旧结果缺格式版本视为原兼容格式，未知的新版本明确拒绝。

任务启动先保存运行记录。网页取消与应用退出都停止整个任务子进程组并等待退出；服务退出为 interrupted，主动取消为 cancelled。重启时无运行中管理器的旧 running 记录显示 interrupted。checkpoint 使用原子替换，损坏可见且可重新检查源 receipts。

服务启动由应用 lifespan 注册本工作区 PID；关闭等待任务清理。macOS 便利脚本只停止登记且仍监听指定端口的本项目 PID，使用 SIGTERM。

唯一执行日期语义来自已公布交易日历；缺覆盖时返回 null。未来日历安排可以查询，行情截止日仍固定为本次已收盘边界。
