# 日频横截面策略：区间标签与下一轮特征工程

核验日期：2026-07-16（Asia/Shanghai）

## 结论

下一轮不应继续把“下一天涨幅”作为唯一监督信号。最先做的、且与当前五个每日轮换子组合最一致的比较是：

1. 保留端点标签作为基准：信号日 `T` 收盘后生成特征，`T+1 open` 建仓，`T+6 open` 退出，标签为五个交易日的可交易区间收益；
2. 新增五日路径标签：对 `T+2 ... T+6` 每个开盘相对 `T+1 open` 的累计收益取均值，再按当日行业和 `log(float_market_cap)` 中性化、横截面排名；
3. 只在 2021-01-01—2023-12-31 开发期比较这两个标签。不得读取、汇总或据此调节 2024-01-01—2026-05-22 留出期的指标；只有开发期规则冻结后才能再次运行留出期。

五日端点标签直接对应真实退出日，解释最简单；路径标签则奖励整段持有期内较早且持续的上涨，减少“退出日单点跳变”对监督信号的支配。后者是一个面向本策略持仓路径的工程假设，不是已有论文已经证明在 A 股日频上必然更优的结论，必须由开发期净成本回测验证。

公开证据支持“预测区间收益、而非执着于下一日”的研究方向，但没有可靠原始资料证明 5、10 或 20 日中某一个窗口对本仓库必然最优。Microsoft Qlib 的 Alpha158/Alpha360 官方实现默认使用下一期收益标签，说明它适合作为可复现基准，而不是唯一目标；其官方基准同时以未来收益相关性和组合收益评价信号。[Qlib 标签源码](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/handler.py)；[Qlib 官方基准](https://github.com/microsoft/qlib/blob/main/examples/benchmarks/README.md)。Leippold、Wang、Zhou 在 3,900 多只 A 股上预测一个月前瞻收益，并发现流动性变量对中国市场最重要；这支持测试较长区间和流动性特征，但论文是月频，不能直接当作五日日频结论。[原始 JFE 论文](https://doi.org/10.1016/j.jfineco.2021.08.017)。

## 可立即实现的标签定义

设 `O(T+k)` 为第 `T+k` 个交易日的、与回测执行口径一致的开盘价。所有特征只使用 `T` 收盘时已知的信息。

### A. 五日端点收益（基准）

```text
y_endpoint_5(T) = O(T+6) / O(T+1) - 1
```

这是实际五日子组合的开仓至计划退出收益。标签到 `T+6` 才完整可得，因此 `label_available_date = T+6`。

### B. 五日路径均值（本轮首选实验）

```text
y_path_5(T) = mean_k[ O(T+1+k) / O(T+1) - 1 ],  k = 1..5
```

它等价于评价五个可能退出开盘的平均持有期收益，而不是只评价最后一个开盘。实现时必须要求五个路径价格完整；缺失、停牌或涨跌停导致的不可执行样本不能静默以前向价格填充。应单独报告标签缺失率及其在市值、行业、ST/停牌状态上的分布，否则模型可能只学习“未来可交易样本”。

### C. 中性化与排名

对 A、B 分别执行：

```text
raw target
  -> 当日可选股票内回归：industry dummies + zscore(log float market cap)
  -> 取残差
  -> 当日横截面百分位映射到 [-1, 1]
```

横截面排名能降低极端收益对平方损失的影响。国际股票的原始大样本研究直接比较了原始收益与百分位排名收益，后者在其模型组合中表现更好；但该证据是月频且非专门针对 A 股，所以这里只把排名作为固定预处理，不外推论文收益数字。[原始研究](https://link.springer.com/article/10.1057/s41260-023-00318-z)。残差收益可以隔离一部分共同风险；Residual Momentum 的原始研究表明基于残差收益构造的动量与总收益动量具有不同的风险调整表现，但它研究的是历史残差动量，不是本策略的前瞻标签，因此只支持“值得做受控比较”，不构成胜出保证。[Residual Momentum](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2319861)。

## 本轮只增加八个日线特征

避免一次复制完整 Alpha158。下面八项均可由现有 OHLCV、成交额/换手率构造，先在完整交易日序列上滚动，再在信号日过滤股票池；所有连续值仍按当日 1%/99% 去极值和横截面排名。

| 特征 | 建议定义 | 目的 |
|---|---|---|
| `overnight_gap_mean_5` | `mean(open / prev_close - 1, 5)` | 分离隔夜定价与日内走势 |
| `close_location_mean_10` | `mean((close-low)/(high-low+eps), 10)` | 衡量收盘在日内区间的位置 |
| `trend_r2_20` | 过去 20 日收盘价对时间回归的 `R²` | 区分平滑趋势与噪声跳动 |
| `trend_residual_20` | 上述回归末端残差 / 当前收盘 | 捕捉相对局部趋势的偏离 |
| `downside_vol_20` | 过去 20 日负收益的均方根 | 区分相同总波动下的下行风险 |
| `range_vol_10` | `mean((high-low)/prev_close, 10)` | 利用 OHLC 区间补充收盘波动 |
| `price_volume_corr_20` | 过去 20 日收益与 `log1p(amount)` 变化的相关系数 | 捕捉价量确认或背离 |
| `turnover_shock_5_20` | `mean(turnover,5) / mean(turnover,20) - 1` | 捕捉短期拥挤和流动性突变 |

Qlib 的官方 Alpha158 源码采用 5/10/20/30/60 日窗口，并公开实现 K 线形状、趋势斜率、`R²`、趋势残差、区间位置、价格—成交量相关和上涨日占比等特征；上表沿用这些可审计的特征族，但缩小到八项。[Alpha158 官方特征源码](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)。A 股原始研究还把 20 日波动、20 日 MAX、Amihud 非流动性、20/250 日异常换手和 20 日反转列为可检验特征，并以五个每日切片持有五日；这与当前轮换结构直接相容。[Size and Value in China](https://www.nber.org/system/files/working_papers/w24458/w24458.pdf)。Leippold、Wang、Zhou 的 A 股研究中，成交额/换手波动、零交易天数和非流动性是最重要的一组预测变量，支持优先增加换手冲击和价量特征。[原始 JFE 论文](https://sribd-kaizhang.github.io/quantdoc/pdf/machine_learning_in_the_chinese_stock_market.pdf)。

本轮不要同时再加入大量估值交叉项。现有 `EP/PB/ROE/log-size` 继续作为慢变量锚；等标签比较完成后，再单独预注册行业相对 EP、EP 变化、估值×流动性等第二批特征，避免无法判断收益变化究竟来自标签还是特征。

## 重叠、泄漏与 purge

相邻五日标签共享四段未来收益，日度 IC 和损失序列天然高度相关。Nelson 与 Kim 的原始研究明确指出，多期重叠收益会按构造产生正自相关，并可能放大表面预测力。[NBER 原文](https://www.nber.org/papers/w3297)。因此：

- 任一训练行只有在 `label_available_date <= prediction_date` 时才能拟合；
- 任一独立训练/验证切分使用保守的 `gap=5` 个交易日；scikit-learn 官方 `TimeSeriesSplit` 的 `gap` 就是从训练集末端到测试集之间排除的样本数。[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)；
- 同一日期的所有股票必须在同一个 fold，不能随机拆分横截面；
- IC 显著性至少使用 `H-1=4` 阶 HAC，或按五个互不重叠的 weekday/cohort 分开报告；普通独立同分布标准误无效；
- 开发期末只保留 `label_available_date <= 2023-12-31` 的样本。不能为了计算 2023 年最后若干信号的五日标签而读取 2024 年价格；以交易日历动态确定最后一个合格信号日；
- 10/20 日标签若进入后续实验，purge/gap 和开发期末截断同步扩大到最长 20 日，不能仍沿用五日边界。

## 开发期预注册比较

本轮只做一个二选一实验，控制多重尝试：

| 项目 | 基准 | 候选 |
|---|---|---|
| 监督目标 | `target_rank`（五日端点残差排名） | `target_path_rank`（五日路径均值残差排名） |
| 特征 | 原特征 + 上述固定八项 | 完全相同 |
| 模型 | 固定因子、Elastic Net、浅层 GBRT；参数和随机种子相同 | 完全相同 |
| 组合 | 五个每日子组合、持有五日、相同缓冲/容量/成本 | 完全相同 |
| 选择区间 | 2021、2022、2023 三个开发年度 | 完全相同 |
| 留出期 | 不读取 2024-01-01—2026-05-22 指标 | 不读取 |

选择顺序固定为：

1. 比较每年日度 Rank IC、正 IC 日占比，并同时报告五个不重叠 cohort 的 IC；
2. 比较历史时变费用与固定 20bp 往返成本下的净年化收益、Sharpe、最大回撤、换手和未成交积压；
3. 路径标签只有在三个开发年度中至少两个年度的净收益和 Sharpe 同时高于端点基准，且全期最大回撤没有恶化超过 2 个百分点、20bp 压力下仍领先时才胜出；
4. 若结果分裂或只靠一个年份/一个子组合，保留端点标签；不得通过查看留出期来打破平局；
5. 保存两个候选的全部结果和试验编号。冻结胜者后，才允许一次性运行 2024-01-01—2026-05-22；该区间此前已被仓库其他研究使用，因此即使胜出也仍需前瞻纸面交易确认。

## 后续而非本轮的标签扩展

完成上述二选一后，可预注册第二阶段：`T+1 open -> T+11 open`、`T+1 open -> T+21 open`，以及分别训练 5/10/20 日模型后对三个预测横截面排名做固定权重合成。多视距方法的原始研究说明同时预测多个未来步能提供整段路径信息，但它不是股票收益专用证据，所以应先采用“独立浅层模型 + 固定排名合成”，不因标签变化立刻引入复杂 Transformer。[Temporal Fusion Transformer 原始论文](https://arxiv.org/abs/1912.09363)。任何 10/20 日候选仍要用实际五日组合净收益作为最终经济评价；标签 IC 更高但五日可交易组合收益更差，不算优化成功。
