# 策略复盘与经验沉淀

> 每个策略的精华与教训。设计新策略前先读这份文档，取其精华，弃其糟粕。

## crowding_price_volume

防守反击型规则策略。6.5 年（2020-01 → 2026-07）回测：年化 14.6%，Sharpe 1.12，最大回撤 -17.7%，Beta 0.18。日均仓位仅 32.5%，7 年中 6 年正超额。

### 值得带走的设计

**出场端才是 alpha 来源**

这个策略最大的发现：稀疏事件策略的收益不在「选到好票」，而在「让好票跑够、把坏票砍快」。v2.0 到 v2.4 仅改出场体系（止损收紧 → trailing 8%/7%），总收益从 +51.6% 涨到 +92.7%，翻了近一倍。实际回测中 `take_profit` + `stall_take` 两个止盈出场贡献了 96.9% 的总盈利。如果新策略也是低频事件驱动，先把出场打磨好，再纠结入场。

**Risk-On：放大暴露而非加 beta**

在 12.8% 的交易日（HS300 趋势向上 + 市场宽度 ≥30%）将仓位从 26% 提到 75%，贡献 +41.6pp 收益。关键设计：不做 Volatility Targeting、不放宽开仓 funnel、不换因子——只在已有高质量信号上乘 1.25。本质是「好日子多花钱」，不是「赌好日子会来」。

**四层分工架构**

Regime（能不能做）→ Timing（何时做）→ Risk（该不该收手）→ Quality（买的质量）。每层独立判断，通过决策矩阵组合出 `action`。好处是 debug 时可以逐层归因：收益不对先查 Regime，胜率不对查 Timing，回撤不对查 Risk。新策略如果涉及多维度判断，强烈建议分层而非堆一个大模型。

**消融实验驱动迭代**

每个版本改动都有对照实验（同一面板、只改一个变量）。v2.5 评估 6 个 SOTA 因子，只采纳 1 个（turn_cv_20），其余 5 个在消融中伤收益被弃用。没有消融就不知道是哪个改动在起作用——v3.2 假牛熔断的 Bug 就是因为没有在修复后的代码上重新验证，导致原始数据不可信。

**换手稳定性因子**

`turn_cv_20`（20 日换手率变异系数）是唯一被采纳的 SOTA 因子。逻辑契合：策略要「缩量后放量 thrust」，低换手波动的股票更可能是机构控盘而非散户噪声。消融中 +13.2pp，是因子叠加阶段贡献最大的单个因子。

**资金流作为最后一级确认**

北向 `north_z_60` + 两融 `margin_z_60` 作为面板第 5 级 enrichment，在入场排序中给予资金流强的股票更高权重。+14.2pp 贡献。资金流不作为独立信号，只作为已有信号的确认层——这个定位很重要。

**防御性仓位即 alpha**

日均仓位 32.5% 意味着 67.5% 时间持有现金。2022 年 HS300 -22% 时策略 +5.5%（超额 +27.6pp），核心就是「不做的时候不亏」。新策略不要害怕低仓位，现金本身是一种 position。

### 需要警惕的陷阱

**照搬连续暴露类 SOTA**

Volatility Targeting、风险平价、因子动量——这些在连续满仓策略中有效的技术，在稀疏事件策略中全部失败。消融中 Vol Targeting 把收益从 +75% 砸到 +25%。原因：稀疏策略的信号本身就自带择时，再叠加波动率缩放等于双重择时，信号本就少的日子的仓位被进一步压缩。

**硬过滤与信号逻辑冲突**

`anti_chase`（防追高）硬过滤买入数为 0——因为 `open_A = thrust_up` 天然有正 `ret_5`，追高过滤把所有信号都杀了。`path_eff` 硬过滤伤收益 -40pp——因为 thrust 的路径效率天然低于平滑趋势。教训：加过滤前先理解信号的统计特征，不要拿理论去砍实证有效的信号。

**放宽 funnel 等于自杀**

全局放开 `structure_attack` 入场导致大亏。稀疏是 feature 不是 bug——213 笔买入 / 6.5 年 = 每月不到 3 笔，这个频率正好匹配 A 股 meaningful 的价量突破事件。放宽标准会引入大量噪声信号，把策略从「精准狙击」变成「散射」。

**假牛熔断的粗糙实现**

原始设计意图正确（连续双缩时禁止暴露加成），但实现过于粗糙：仅做暴露 on/off，触发率 15.4% 过高。实际消融 -1.8pp，与原始实验日志的 +8.1pp 矛盾。教训：复杂 overlay 必须在最终代码上重新验证，不能信任中间代码路径的结果。

**MFE exit 在非趋势行情中误杀**

`mfe_exit`（MFE 未达阈值退出）是最大亏损源：44 笔仅 5 笔盈利，合计 -57.5 万。问题在于 A 股很多突破后横盘消化而非直接拉升，MFE 阈值把「正常消化」误判为「 thesis 失效」。新策略如果用 MFE 出场，务必区分「横盘消化」和「趋势终结」。

**集中持仓不适用于稀疏策略**

`top_n=3` 收益略升但 Sharpe 和回撤变差。稀疏策略每月不到 3 笔买入，集中到 3 只等于把单笔风险放大。`top_n=5` 是经过校准的平衡点。

### 可迁移的设计模式

| 模式 | 做法 | 适用场景 |
|------|------|----------|
| 双层量能 | 大盘 × 行业成交额 vs 中位数，组合出 5 级 attack_mode | 任何需要择时的 A 股策略 |
| ASOF join 对齐 | 事件数据（股本/涨跌停）用 DuckDB ASOF 携带最后已知值 | 任何混合日线 + 事件数据的策略 |
| 五级 enrichment 管线 | 基础面板 → SOTA 因子 → 行业拥挤 → 事件封锁 → 资金流 | 面板构建流程 |
| 消融实验模板 | 同一面板只改一个变量，记录 total_return / Sharpe / 胜率 / 买入数 | 所有策略迭代 |
| trailing 8/7 出场 | 8% 激活、7% 回吐止盈 | 趋势跟踪类策略 |
| 真实成本口径 | 佣金 2.5bp + 过户 0.1bp + 印花税 5bp + 分档滑点 3/8/20bp | 所有 A 股回测 |

### 不可迁移的（仅适用于本策略）

- `dry_up_base → thrust_up` 的两步买点逻辑——依赖 A 股散户结构特有的缩量-放量节奏
- `crowding_score` 的 ret_pct + turn_pct 均值——拥挤度定义与策略的价量 thrust 信号强耦合
- 科技股 PS 优先、非科技 PE 优先的估值分桶——是本策略 alpha 假设的一部分，不是通用最佳实践

## rotating

全市场日频横截面轮动：流动性、低风险、价值与反转特征输入浅层 GBRT，五个日度子组合在 T+1 开盘执行。当前仅为 research-only。

### 值得带走的设计

**非线性交互必须与简单基线同场赛马**

固定因子、Elastic Net 与 GBRT 使用完全相同的标签、训练窗、股票池和成交引擎。早期幸存者偏差样本偏好等权集成，正式全市场样本却由浅层 GBRT 胜出；模型复杂度只能由同口径封存结果证明。

**标签可得日比简单 shift 更重要**

五日标签记录 `label_available_date=T+6`，季度训练只接受当日已经实现的标签。这样既保留重叠样本，又不会在季度首日读到未来收益。

**挂单是组合状态，不是回测异常**

停牌、一字涨跌停订单必须滚动；同一 sleeve 的卖单未成交前，替代买单不能突破目标持仓数。卖单成交后再按“先卖后买”顺序执行替代单。

### 需要警惕的陷阱

**供应商日度估值不等于完整公告日财务层**

日期化 PE/PB 快照避免了当前值回填，但公开 release 没有可独立核验的公告日质量字段。隐含 ROE 与缺失指示可以做研究，不能替代 `financial_pit` 的生产审计。

**集中持仓没有提高开发期收益**

10/15/20 只配置均未超过预设的 25 只分片组合；非线性排序的头部差异不足以抵消个股噪声和行业容量约束。

**高 ICIR 不能直接当显著性**

五日标签重叠会夸大朴素 ICIR。必须报告稳健误差、尝试次数和 DSR，并用未参与调参的纸面交易继续验证。

### 可迁移的设计模式

| 模式 | 做法 | 适用场景 |
|---|---|---|
| 日期化标签闸门 | 训练条件显式要求 `label_available_date <= prediction_date` | 所有重叠前瞻标签 |
| 五日分片 | 每日只更新一个 sleeve，降低集中换仓冲击 | 日频多因子轮动 |
| 模型赛马 | 固定因子、线性模型、浅层树共享数据与执行 | 任何 ML alpha 验证 |
| 研究准入状态 | 适配器显式返回 research-only 与未完成门槛 | 未完成前瞻验证的策略 |

### 不可迁移的

- `PB/PE` 隐含 ROE 仅是本次公开数据降级方案，不应覆盖已有公告日财务层；
- 当前 GBRT 参数和 25 只持仓结论依赖本样本与五日标签，不能直接复制到其他频率；
- 2024—2026 封存结果已被查看，后续任何参数变化都必须归入新的前瞻版本。
