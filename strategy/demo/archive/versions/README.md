## 版本演进与真实贡献复盘

### 出场体系（v2.0 → v2.4）

| 版本 | 关键改动 | 总收益 | Sharpe | 真实贡献评估 |
|------|----------|--------|--------|-------------|
| v2.0 | 基础面板 + 简单出场 | +51.6% | 0.54 | 基线 |
| v2.1 | 止损收紧 + 出场三件套 | +79.4% | 0.74 | **+27.8pp · 胜率 41%→55%** |
| v2.3 | R-scale 出场 + MFE exit | +74.8% | 0.70 | -4.6pp（MFE 过激，后续保留但需优化） |
| v2.4 | Trailing 8%/7% | +92.7% | 0.83 | **+17.9pp · 让利润奔跑** |

**核心教训**：出场体系是策略的第一大 alpha 来源。从简单止损到 trailing 8/7，
总收益翻了近一倍。但 MFE exit 在非趋势行情中频繁误杀（当前仍是最大亏损源 -57.5 万）。

### 因子叠加（v2.5 → v2.8）

| 版本 | 关键改动 | 总收益 | Sharpe | 真实贡献评估 |
|------|----------|--------|--------|-------------|
| v2.5 | 换手稳定性 score | +105.9% | 0.91 | **+13.2pp · 过滤散户噪声换手** |
| v2.6 | 行业拥挤 + 财报封锁 | +107.3% | 0.91 | +1.4pp（边际改善） |
| v2.7 | 事件封锁 + 指数分层 | +109.7% | 0.93 | +2.4pp（风险控制） |
| v2.8 | 北向 + 两融资金流 | +123.9% | 1.00 | **+14.2pp · 资金流确认有效** |

**核心教训**：换手稳定性（turn_cv_20）和资金流是有效的因子增量。
path_eff 和 anti_chase 在消融中伤收益，已弃用——稀疏事件策略不应照搬连续暴露类因子。
