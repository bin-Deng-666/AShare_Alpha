---

## 1. Alpha 假设（赚什么钱）

1. **市场与板块量能**决定进攻窗口：大盘缩量时少开多；大盘一般但行业放量时做结构；两层都放量时才大胆做强势。
2. **个股价量配合**决定时机：放量上涨可参与；高位滞涨/高潮放量/放量破位应收手；缩量企稳后再放量是二次买点。
3. **拥挤**决定风险：拥挤高且价量恶化时，继续追高的期望变差（含催化落地后的 sell-the-news），应减仓或回避。
4. **相对估值**决定买的质量：用行业内分位；科技方向优先 PS/PB，不用跨行业绝对 PE 一刀切。

**明确不赌：**「业绩好看 → 产业一定涨」。公告/业绩若使用，只作拥挤催化的时间戳，不作多头主理由。

---

## 2. 失效条件

- 强趋势扩散期：全市场与热点行业额能中枢抬升、涨停溢价仍高，过早做「兑现减仓」会反复止损 → 提高买点 B 权重、降低过早减仓。
- 流动性危机：大盘 `shrink` 且波动极端 → 关闭新开多，策略以防御为主。
- 估值门禁若变成「无脑买低 PE」，科技与成长股会系统性踏空 → 必须行业/科技口径。
- 形态参数漂移或触发频率异常升高 → 暂停加复杂度，先查数据与过拟合。

## 4. 买 / 持 / 减（主线完整闭环）

> **v1.0 实盘/回测默认只启用买点 A。** 买点 B/C 仍由面板打标、规格保留，但 `enable_open_b/c=False`，组合与日荐默认不执行。

### 4.1 买点 A — 回撤后再启动（主 · v1.0 启用）

- 前置：双层量能允许进攻（非双缩、非仅许防御）。
- 个股：先有 `dry_up_base`，再出现 `thrust_up`。
- 拥挤：从高位回落或未顶格。
- 估值：通过行业/科技门禁（非「对本行业极端贵」）。

### 4.2 买点 B — 量能扩张期强势确认（规格保留 · v1.0 默认关）

- 前置：大盘 `expand` 或 `neutral`，且行业 `expand`（结构行情允许大盘 `neutral` + 行业 `expand`）。
- 个股：`thrust_up`（价强 + 额能配合），禁止缩量阴涨当买点。
- 拥挤：中等及以下偏好；顶格拥挤不追。
- 估值：门禁通过。
- 开关：`params.enable_open_b`。

### 4.3 买点 C — 龙头滞涨后的补涨（卫星 · v1.0 默认关）

- 同行业龙头出现 `stall_high` 或 `climax_volume`。
- 候选：`rotation_wake` + 估值不极端贵 + 双层量能非防御。
- 单票与卫星总仓上限低于主买点。
- 开关：`params.enable_open_c`。

### 4.4 持仓

- `thrust_up` 仍成立，拥挤未失控，双层量能未落入「关闭新开且需减仓」组合。

### 4.5 减仓 / 回避

- 拥挤高 ×（`stall_high` | `climax_volume` | `break_down_vol`）；估值偏贵则加重。
- 行业量能由 `expand` 拐向 `shrink`：同板块持仓整体降权。
- 大盘进入 `shrink` 或 `climax_mkt`：按决策矩阵降仓或禁追。

## 5. 日终流水线

```text
1. 构建当日可交易宇宙（ST/停牌/涨跌停/流动性/次新等）
2. 计算 MktVol、各行业 IndVol → 组合 Regime + 仓位乘数
3. 个股：价量形态、拥挤分、估值分位（行业/科技口径）
4. 按 decision_matrix 生成动作：open_A / open_B / open_C / hold / reduce / avoid  
   （**v1.0 组合与日荐默认只执行 open_A**；B/C 需显式打开开关）
5. 组合层：权重、换手预算、可成交性
6. 输出目标持仓与信号解释字段（可归因）
```

日终产物可直接做成 **下一交易日行动清单**（新开 / 持有 / 减仓 / 今日空仓），见 §10。

## 7. 不做清单

- 裸 PE/PB 绝对值选股、无条件动量/反转、无成本全市场扫股
- 「业绩超预期 → 自动买产业链」主逻辑
- 堆叠过多 K 线口诀；形态超过规格书列表须先开实验
- 端到端深度学习选股（本阶段）

## 8. 验证计划（Phase 3）

### 8.1 样本区间约定

| 用途 | 默认区间 | 说明 |
|------|----------|------|
| **主回测 / 调参** | **2020-01-01 至今** | 贴近当前微观结构与交易生态；参数只在此优化 |
| **样本外 / walk-forward** | 主区间内切最后 1–2 年，或滚动向前 | 防过拟合 |
| **压力检验** | 2015、2018、2022 等 | **只读不调参**：问会不会爆，不当优化目标 |
| **更早历史** | 默认不用于定参 | 最多作稳健性附录 |

原则：**优化看近，压力看远，结论以近为主。** 若某规则仅在 2015 前有效、近五年失效 → 弃用。

### 8.2 报告内容

- 条件事件研究：各买点 / 减仓条件后的前瞻收益分布
- 对照：无双层量能 / 无估值门禁 / 无拥挤 → 证明模块增量
- 科技子集单独报告（PS/PB 口径）
- 成本三档、分年度、分 `attack_mode` 报告
- 拥挤与常见因子相关性、换手、最大回撤归因

## 10. 每日荐股 / 行动清单（产品形态）

**可以。** 本策略日终天然产出下一交易日清单，适合做成「每日行动建议」，而不是「每日必推 N 只热股」。

| 可以 | 注意 |
|------|------|
| 收盘后跑信号 → 给出 T+1 的 `open_A/B/C`、`hold`、`reduce`、`avoid` | 防御 regime 时可能 **零新开**，这是正确行为，不要硬凑荐股 |
| 每只带 `reason_codes`（量能、价量、拥挤、估值） | 荐股应是 **组合子集**，受单票/行业/卫星仓上限约束 |
| 同时输出「今日不追 / 建议减仓」名单 | 默认研究信号，不构成投资建议；实盘还要过涨跌停与流动性 |

推荐日报字段：代码、动作、建议权重或优先级、四层状态摘要、一句话理由。

## 11. v1.0 实际表现摘要（2020-01-02 → 2026-07-14）

> 完整指标见 [`../reports/PERFORMANCE.md`](../reports/PERFORMANCE.md)，版本演进复盘见 [`../archive/versions/README.md`](../archive/versions/README.md)。

| 指标 | 数值 | 评估 |
|------|------|------|
| 总收益 | +143.3% | 6.5 年翻 2.4 倍 |
| 年化收益 | 14.6% | vs HS300 2.5% |
| Sharpe | 1.12 | 风险调整后收益优秀 |
| 最大回撤 | -17.7% | vs HS300 -46.7% |
| Alpha 年化 | 13.6% | Beta 仅 0.18 |
| 胜率 | 59.9% | 盈利因子 1.76 |
| 日均仓位 | 32.5% | 防御性，现金占比高 |

**真正有效的改进（按贡献排序）**：

1. **Risk-On 暴露加成**（+41.6pp）— 在 12.8% 的牛市日放大仓位，是最大的单一 alpha 来源
2. **出场体系**（trailing 8/7 + stall_take）— 止盈机制贡献 96.9% 的总盈利
3. **换手稳定性因子**（turn_cv_20）— 过滤散户噪声换手，提升开仓质量
4. **资金流确认**（北向 + 两融）— 叠加在面板上的最后一级 enrichment

**需重新审视的设计**：

- **假牛熔断**：当前实现下微负贡献（-1.8pp），触发率 15.4% 过高，门控过于粗糙
- **MFE exit**：最大亏损源（-57.5 万，44 笔仅 5 笔盈利），在非趋势行情中频繁误杀
- **拥挤轨迹 + 稀缺溢价**：旧代码库显示 +29.8pp，但依赖 Risk-On 激活，需在当前代码上重新验证
