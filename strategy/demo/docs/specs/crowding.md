# 规格：拥挤分 Crowding

拥挤衡量「短线参与过热程度」。高拥挤不是自动空头，而是：**与价量恶化、估值偏贵叠加时，提高减仓/回避权重；顶格拥挤时禁止追买。**

---

## 1. 目的

- 卖/回避侧：识别「买拥挤」风险（含催化落地后的兑现压力）
- 买侧：顶格拥挤不做买点 B；买点 A 要求拥挤已从高位缓和
- 买点 C：龙头高拥挤 + 滞涨，资金可能切向低拥挤补涨

**不把**「业绩公告」直接当多头信号；若使用公告日，仅可作为催化时间戳特征（可选，第二阶段再加）。

---

## 2. 输入特征（个股，日频）

| 特征 | 说明 |
|------|------|
| 近 k 日涨幅 | 过热代理 |
| 换手率水平与分位 | 参与度 |
| 近 N 日 amount 分位 | 额能拥挤 |
| 相对行业收益 | 是否已被主题资金推高 |
| （可选）近 N 日涨停次数 | 情绪拥挤，需涨跌停数据 |

行业层面可选：`ind_climax` 已由量能规格覆盖，此处以个股为主。

---

## 3. 拥挤分

- 先将各特征在 **行业内截面** 或 **全宇宙截面** 标准化（实现时选定一种并写死）
- 合成 `crowding_score` ∈ [0, 1] 或分位数  
- 分档：

| 档 | 示意 |
|----|------|
| `low` | 拥挤缓和，适合作为买点 A 后半段环境 |
| `mid` | 可做买点 B（叠加价量与估值） |
| `high` | 不追；持仓提高警戒 |
| `extreme` | 禁止新开多；若价量恶化则优先减仓 |

---

## 4. 与其它模块的关系

| 组合 | 行为倾向 |
|------|----------|
| `extreme/high` + `stall_high`/`climax_volume`/`break_down_vol` | 强减 / avoid |
| `extreme/high` + `thrust_up` | 不追新开；存量收紧止盈规则（实现定） |
| `low/mid` + `dry_up_base`→`thrust_up` | 买点 A 候选 |
| 龙头 `high`+滞涨，小弟 `low`+`rotation_wake` | 买点 C |

---

## 5. 输出字段

- `crowding_score`, `crowding_bucket`
- 分项特征（可解释）
- `crowding_version`

---

## 6. 验收

- 与裸 20 日动量相关但不全同（应含换手/额能）  
- 高拥挤子集在「价量恶化」后的回撤应大于低拥挤子集（诊断报告）  
- 监控：拥挤分分布漂移、与持仓重叠度
