# CHANGELOG

## v0.2 后续研究 — 固定市场门控被拒绝（2026-07-16）

- 研究并事前否决 5/10/20 日多模型赛马；现有标签继续是 `T+1` 到 `T+6` 的五日区间涨幅，而非次日涨幅；
- 增加可审计的沪深 300 十个月月末趋势状态和可选组合入场门控，risk-off 取消待买但不阻断卖单；
- 只用物理截止 2023-12-31 的既有开发分数运行唯一固定候选；候选年化 -3.13%、Sharpe -0.34，落后 v0.2 的 -0.98%/-0.06，故不升级默认策略；
- 候选最大回撤改善至 -17.89%，但收益与跨年度门槛失败；完整结果见 [`../experiments/20260716_market_gate_feature_race.md`](../experiments/20260716_market_gate_feature_race.md)。

## v0.2 — 区间标签与日线特征增强（2026-07-16）

- 默认监督目标改为 `T+6 open / T+1 open - 1` 的五日端点区间涨幅，而不是下一日涨幅；
- 两种候选标签共用完整可执行路径样本，保持 `label_available_date = T+6`；标签收益使用前复权价，可执行性使用原始价并与回测引擎的一字涨跌停规则一致，停牌/不可执行时不生成标签且禁止前向填充；
- 增加隔夜缺口、收盘位置、趋势质量/残差、下行波动、振幅、价量相关和换手冲击八项特征；
- 使用物理截止于 2023-12-31 的面板只比较端点/路径标签；路径标签仅在 2021 年收益和 Sharpe 双胜且回撤恶化 2.68pp，未通过预注册门槛，故冻结五日端点标签；
- 冻结增强特征与端点标签后，一次性重跑 2024—2026-05-22 封存期；GBRT 年化 13.24%、Sharpe 0.99、最大回撤 -9.18%，状态仍为 research-only；
- 在 JSON/Markdown 报告中分开记录实际端点收益 IC 与模型训练标签 IC，并补充 HAC(4)、逐年、五 cohort、换手、积压和完整评分配置；
- 冻结结果见 [`../versions/v0.2/`](../versions/v0.2/)，完整赛马见 [`../experiments/20260716_interval_label_feature_race.md`](../experiments/20260716_interval_label_feature_race.md)。

本版本遵守预注册开发期选择；封存结果只作泛化报告，没有用于事后修改标签或继续调参。
