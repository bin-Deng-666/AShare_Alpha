# CHANGELOG

## v0.2 — 区间标签与日线特征增强（2026-07-16）

- 明确默认监督目标为 `T+1 open -> T+6 open` 五日区间涨幅，而不是下一日涨幅；
- 实现完整五日路径均值标签，并保持 `label_available_date = T+6`、禁止缺失路径前向填充；
- 增加隔夜缺口、收盘位置、趋势质量/残差、下行波动、振幅、价量相关和换手冲击八项特征；
- 只在 2021—2023 开发期比较原/增强特征与端点/路径标签，路径标签因未通过 20bp 成本压力门槛而不采纳；
- 冻结增强特征与端点区间标签后，一次性重跑 2024—2026-05-22 封存期；GBRT 年化 10.84%、Sharpe 0.78、最大回撤 -11.40%，状态仍为 research-only；
- 在 JSON/Markdown 报告中分开记录实际端点收益 IC 与模型训练标签 IC；
- 冻结结果见 [`../versions/v0.2/`](../versions/v0.2/)，完整赛马见 [`../experiments/20260716_interval_label_feature_race.md`](../experiments/20260716_interval_label_feature_race.md)。

本版本遵守预注册开发期选择；v0.2 封存表现低于 v0.1 的差异只作泛化报告，没有用于事后撤销选择或继续调参。

## v0.1 — 浅层非线性日频轮动（2026-07-16）

- 新建 5 日分片、T+1 开盘执行的沪深 A 股横截面策略；
- 固定因子、Elastic Net、浅层 GBRT 三方滚动赛马，季度冻结、三年训练窗；
- 修复日期化费用、注册制 IPO 前五日无涨跌停、停牌/一字板挂单与容量约束；
- 正式比较开发期 2021—2023 与封存期 2024—2026-05-22，严格截断成交与 Rank IC 标签的公开测试边界，并补充固定成交路径的 20/40/80bp 成本压力；
- 选择 GBRT 作为默认研究信号；由于 DSR、前瞻纸面交易和公告日财务质量门槛尚未完成，状态保持 research-only；
- 冻结结果见 [`../versions/v0.1/`](../versions/v0.1/)。

本版本吸收 `experiments/20260716_initial_model_race.md` 与 `20260716_formal_full_market.md` 的结论；封存段打开后不再调参。
