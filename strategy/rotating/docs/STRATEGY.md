# 策略总述：rotating

| 项 | 内容 |
|---|---|
| 策略 ID | `rotating` |
| 频率 | 日频；信号日 T 收盘后决策，T+1 开盘成交 |
| 市场 | 沪深 A 股；北交所暂不纳入 |
| 定位 | 5 日分片的横截面因子 / Elastic Net / 浅层 GBRT 轮动 |
| 研究依据 | [`daily_strategy_research.md`](../../../docs/research/daily_strategy_research.md)；[`interval_label_feature_engineering.md`](../../../docs/research/interval_label_feature_engineering.md)；[`multihorizon_daily_feature_engineering.md`](../../../docs/research/multihorizon_daily_feature_engineering.md) |

## 1. 目标与边界

目标是在真实交易成本和 A 股成交约束下，提高样本外净收益；不以单次全样本最高收益为目标。非线性模型只有在封存样本上同时超过固定因子与 Elastic Net，才可成为默认研究模型；通过第7节全部门槛及前瞻纸面验证前不得称为生产模型。

第一版不做深度学习、当日回转、盘后固定价格的历史回填、当前成分回填历史、当前名称 ST 过滤或北交所混合建模。

## 2. 四个公共 seam

1. `build_factor_panel(start, end, ...)`：从完整交易历史计算截至 T 日可得特征，最后才应用信号日股票池过滤；返回特征、标签可得日与执行字段。
2. `walk_forward_score(panel, ...)`：同一日期的横截面不可拆 fold；每个 T 日预测只能使用 `label_available_date <= T` 的训练行，并输出固定因子、Elastic Net、GBRT 三组分数。
3. `build_monthly_trend_gate(index_bars)`：从真实月末交易日构造下一日历月生效的固定 10 个月趋势状态，保存来源月末与十个实际观测。
4. `run_portfolio(scores, bars, ..., entry_gate=None)`：把 T 日分数转为 T+1 开盘成交，维护 5 个日度子组合和未成交订单，处理 T+1、停牌、一字涨跌停、100 股取整、容量与历史时变成本；可选状态只拦截新买单，不拦截卖单。

测试只通过这三个公共接口观察行为，不测试内部 helper。

拟定的验收示例：

- `build_factor_panel`：在 25 日小面板中插入一个低成交额日，该日仍必须进入前序 rolling；日期化 ST 只排除当日，当前名称不影响历史；缺失 PE 产生缺失标志且不能得到最高价值分。
- `walk_forward_score`：修改预测日之后的目标值，预测必须逐字节不变；`label_available_date > prediction_date` 的行不得进入拟合；同一天全部股票只能属于同一时间 fold。
- `build_monthly_trend_gate`：只使用已结束月份的最后交易日；不足十个月和等于均线时为关闭，状态只能影响下一月。
- `run_portfolio`：T 日信号只能在 T+1 开盘成交；一字涨停买单和一字跌停卖单必须积压；买入按 100 股取整；2023-08-28 前后的卖出印花税应不同；同一子组合首次退出复核至少等待五个交易日而非五个日历日，仍在 top 25% 时按缓冲继续持有。

## 3. 数据时序

```text
完整日线（含低流动性/停牌前后观测）
  → 250 交易日热身与滚动特征
  → 当日 point-in-time 行业、ST、股本/市值
  → 信号日股票池过滤
  → 当日横截面去极值/排名
  → T+6 open / T+1 open - 1 的五日端点区间标签（只供训练）
  → label_available_date = T+6
```

硬约束：

- 不使用当前证券简称过滤历史 ST；只用日期化 `is_st`。
- 缺失估值保留缺失指示，不把 NULL 排到“最便宜”。
- 上市至少 120 个交易日；近 20 个交易日至少 15 个有效观测。
- 先计算滚动特征，再应用成交额、市值、ST 等 eligibility。
- 评估起日前加载至少 250 个交易日；持有期使用交易日编号。

## 4. 特征与标签

基础版约 20 个特征：

- 收益：5/20/60 日收益、20—5 与 120—20 日动量、20 日反转；
- 风险：20/60 日波动、20 日 MAX、60 日回撤、趋势质量；
- 流动性：20/250 日异常换手、5/20 与 20/60 日异常成交额、成交额/换手波动、Amihud、近 20 日 ADV；
- 慢频锚：日期化供应商 PE/PB 快照及由 `PB/PE` 推导的隐含 ROE；只使用信号日文件中实际存在的值，不按报告期回填；
- 控制项：log 流通市值、板块、日期化行业，以及每个估值字段的缺失指示。供应商 release 未提供可独立验证的公告日质量字段，因此这是正式 PIT 财务层的已知降级。

v0.2 在开发期预注册并采纳八项日线特征：五日隔夜缺口、十日收盘位置、二十日趋势 `R²`、二十日趋势残差、二十日下行波动、十日振幅、二十日价量相关和 5/20 日换手冲击。它们与基础特征一样先在完整历史序列滚动，再做信号日横截面排名。

数值特征按信号日横截面 winsorize 后映射到 `[-1, 1]`。v0.2 的主标签是 `T+6 open / T+1 open - 1` 的五日端点区间涨幅，而不是下一日涨幅；标签经日期化行业和 log-size 中性化后映射到横截面 `[-1, 1]`，到 `T+6` 才可用于训练。`T+1` 必须可买，`T+2 ... T+6` 五个路径开盘必须可卖；缺失、停牌、T+1 一字涨停或路径日一字跌停时，两种候选标签同时置空且不前向填充。标签收益使用前复权开盘价，可执行性使用原始 OHLC 与涨跌停价，口径与回测引擎一致。路径均值标签保留为开发期已拒绝候选。

## 5. 模型赛马与防过拟合

每个滚动训练窗强制产生三条预测：

1. 固定方向等权：低异常换手、低波动、低 MAX、正 EP/ROE，加受门控的短期反转；
2. Elastic Net：作为低方差线性基线；
3. 浅层 GBRT：叶节点 7—15、深度约 2—3、小学习率、强最小叶样本与 L2。

同一天所有股票属于同一 fold。五日标签要求至少五个交易日 purge；默认按季度重训，只用过去三年且已经完整实现的标签。正式切分固定为 2021—2023 递归开发、2024-01-01—2026-05-22 一次性测试。封存段打开后不再调参，最终仍需前瞻纸面交易。

## 6. 组合与成交

- 每个交易日只更新一个五日子组合；五个子组合叠加，避免一次性全换仓。
- 每片默认 5 只，总持仓目标 15—25 只；进入 top 10%，跌出 top 25% 才退出。
- 单股目标不超过 8%，单行业不超过 20%，单次下单不超过过去 20 日 ADV 的 2%。
- T 日收盘产生 pending；T+1 开盘先卖后买。
- 一字涨停不买、一字跌停不卖、停牌不成交；未成交订单滚动，不能理论价强制成交。
- 费用按成交日期切换印花税/过户费；主报告使用真实费用与分档滑点，并补充 20/40/80bp 全包往返压力。

公共数据与成交层已同步修复：涨跌停比例按主板、创业板、科创板、北交所和日期化 ST 规则计算；费用按成交日表达 2023-08-28 印花税与 2022-04-29 过户费断点。

## 7. 准入门槛

生产默认模型必须同时满足；当前版本尚未全部满足，只能输出研究信号：

- 20bp 主成本下，测试段净年化和 Sharpe 都超过固定因子与 Elastic Net；
- 大多数滚动窗 Rank IC 为正，40bp 压力下不崩溃；
- 收益不集中于微盘、单一行业或单一年份；
- 未成交积压、ADV 容量和最大回撤在约束内；
- 所有尝试计入 DSR/多重检验记录。

未达到门槛时，生产入口回退到表现更稳健的简单基线，而不是继续在同一测试段调参。

## 8. 当前证据状态

正式实验使用仓库本地全市场 raw/qfq 日线、日期化行业区间和公开 SimTradeData `data-cn-2026-05-26` 估值/状态 release。该 release 有 5,432 个估值文件，估值区间从 2015-01-05 到 2026-05-22；缺口主要是 2015 年前退市股与截止日附近的新股，后者也会被 120/250 日热身门槛排除。模型以 2018—2020 为首个三年训练窗。v0.2 使用物理隔离的开发面板，只读取到 2023-12-31；五日端点标签按预注册规则胜出后，才一次性运行 2024—2026-05-22 封存期。当前正式结果如下（历史费用与分档开盘滑点；数值为年化收益 / Sharpe / 最大回撤）：

| 模型 | 2021—2023 开发期 | 2024—2026-05-22 封存期 |
|---|---:|---:|
| 固定因子 | -8.13% / -0.68 / -29.28% | 7.32% / 0.52 / -16.96% |
| Elastic Net | -3.50% / -0.26 / -25.31% | 11.34% / 0.63 / -17.15% |
| 浅层 GBRT | **-0.98% / -0.06 / -25.16%** | **13.24% / 0.99 / -9.18%** |
| 三模型等权 | -7.76% / -0.62 / -30.82% | 7.98% / 0.58 / -17.28% |

端点 GBRT 的平均日度 Rank IC 在开发期/封存期为 0.08719/0.09125，正 IC 日占比为 84.60%/81.20%，HAC(4) t 为 14.15/10.62。报告同时保存逐年和五 cohort 诊断，且只保留 `label_available_date` 不晚于对应边界的标签。固定零成本成交路径上的 20/40/80bp 往返成本压力，开发期年化为 -2.80%/-3.83%/-5.98%，封存期为 13.20%/13.05%/12.74%；成本冲击保持成交路径不变，因此结果随费率单调下降。路径均值标签只在 2021 年收益和 Sharpe 双胜，2022、2023 均落后且回撤恶化 2.68pp，故按预注册门槛选择五日端点标签。完整决策见 [`20260716_interval_label_feature_race.md`](../experiments/20260716_interval_label_feature_race.md)。

v0.2 冻结后的唯一后续候选是固定沪深 300 十个月月度趋势门控。它把开发期最大回撤从 -25.16% 降到 -17.89%，但年化收益从 -0.98% 降到 -3.13%、Sharpe 从 -0.06 降到 -0.34，且逐年收益与 Sharpe 双胜为 0/3；按事前门槛拒绝，默认策略不变。完整失败实验见 [`20260716_market_gate_feature_race.md`](../experiments/20260716_market_gate_feature_race.md)。

封存期沪深 300 年化约 15.38%，高于策略的 13.24%，但其最大回撤约 19.15%，高于策略的 9.18%。GBRT 封存收益和 Sharpe 均高于固定因子与 Elastic Net；封存结果没有被用于调整标签或参数。开发期绝对收益仍为负，且 DSR、公告质量财务 PIT 与前瞻纸面交易尚未完成，浅层 GBRT 因此只能作为默认研究信号，不能宣称稳定产生基准超额或通过生产准入；适配器会显式返回 `research_only_forward_validation_required`。完整结果见开发期和封存期 `PERFORMANCE.md`。
