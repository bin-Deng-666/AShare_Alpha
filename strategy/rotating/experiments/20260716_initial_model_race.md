# 2026-07-16 初始模型赛马

## 目的

在正式全市场 PIT 数据恢复前，用公开可下载的中证 800 当前成分历史行情做冒烟试验，判断固定因子、Elastic Net 和浅层 GBRT 是否值得进入正式实现。该样本按 **2026-07-15 当前成分** 回看 2018—2026，存在明确幸存者偏差，结果不能作为验收或收益承诺。

## 固定设定

- 标签：T+1 开盘到 T+6 开盘五交易日收益；
- 训练：滚动历史窗口，只用已经实现的标签；
- 组合：long-only，五日分片思想的周度近似；
- 比较：固定因子、Elastic Net、浅层 GBRT、三模型等权；
- 开发段：2021—2023；观察段：2024—2026-07；
- 成本：20/40/80bp 全包往返压力；
- 基准：沪深 300。

## 已尝试结果

数值为年化收益 / Sharpe。20bp 主成本：

| 候选 | 2021—2023 | 2024—2026 |
|---|---:|---:|
| 固定因子 | 9.6% / 0.35 | 19.0% / 0.60 |
| Elastic Net | 21.9% / 0.85 | 0.8% / 0.04 |
| 浅层 GBRT | 7.0% / 0.29 | 19.1% / 0.97 |
| 三模型等权 | **23.8% / 0.83** | **18.0% / 0.60** |
| 沪深 300 | -14.1% / -0.89 | 15.3% / 0.79 |

三模型等权在 40bp 下分别约 19.9% / 0.69 与 14.4% / 0.48；在 80bp 下两段年化约 12.4% 与 7.5%。另尝试过更集中 GBRT：观察段约 27.6% / 1.28，但开发段仅约 8.8% / 0.32，状态不稳定，明确不采纳。

## 决策

保留三条预测作为正式赛马输入，默认研究候选为三模型等权；不因后段集中 GBRT 更好看而采用。正式准入必须改用包含退市股、日期化 ST/行业和真实成交约束的本地全市场数据，并分别报告 2021—2023 与 2024—2026，不再针对后段调参。
