# 2026-07-16 区间标签与特征工程赛马

## 预注册边界

- 研究依据与候选定义：[`interval_label_feature_engineering.md`](../../../docs/research/interval_label_feature_engineering.md)；
- 数据快照：公开 SimTradeData `data-cn-2026-05-26` 与仓库 PIT 目录；
- 选择区间：2021-01-01—2023-12-31；物理隔离面板的最大行情日和最大标签可用日均为 2023-12-29，晚于 2023-12-31 的行情或标签为 0；
- 封存区间：2024-01-01—2026-05-22，在开发期选择冻结后只运行一次；
- 模型、季度重训、三年训练窗、随机种子、组合、容量和成本参数保持不变；
- 两个标签使用同一组增强特征和同一组完整可执行路径样本，每个训练样本都要求 `label_available_date <= prediction_date`。

八项增强特征由用户要求和研究预注册直接固定进入两组候选，不再用额外特征赛马决定是否采纳。与 v0.1 的原特征结果只作为回归参考，不构成本轮第二个选择门槛。

## 标签与样本

- 端点标签：`T+6 open / T+1 open - 1`；
- 路径标签：`T+2 ... T+6` 五个开盘相对 `T+1 open` 的累计收益均值；
- `T+1` 必须可买，`T+2 ... T+6` 每个开盘必须可卖；停牌、`T+1` 开盘涨停或路径日开盘跌停会使两种标签同时缺失；
- 不前向填充价格；两种标签均到 `T+6` 才可训练。

开发期有 1,751,687 个合格信号，其中 1,730,041 个具有完整可执行标签，完整率 98.76%。缺失率随流通市值五分位从小到大为 1.57%/1.44%/1.17%/1.06%/0.93%；信号日非 ST 可交易、ST 可交易、非 ST 停牌样本的缺失率分别为 1.27%/7.59%/99.999%。缺失数最多的行业为 C39 电子设备制造（2,646）、I65 软件信息服务（1,612）、C27 医药制造（1,337）、C38 电气机械（1,333）和 C35 专用设备（1,242）。正式模型只使用信号日非 ST 且可交易的合格行。

## 冻结后的封存结果

冻结方案为“八项增强特征 + 五日路径均值标签 + v0.1 GBRT 研究模型”。一次性封存结果为：历史费用年化 11.74%、Sharpe 0.910、最大回撤 -7.45%；20/40/80bp 固定路径年化 11.71%/11.52%/11.14%；对实际端点收益的平均 Rank IC 为 0.09121，对路径训练标签的平均 Rank IC 为 0.08045。沪深 300 同期年化 15.38%。

Elastic Net 封存年化为 12.79%，高于 GBRT 的 11.74%，因此 GBRT 未满足“收益和 Sharpe 同时领先”的生产准入门槛。封存结果没有用于修改选择，状态仍为 `research_only_forward_validation_required`。

## 决策

- 八项增强特征按预注册固定进入默认输入 schema；
- 默认标签改为五日路径均值，不再使用下一日或单一退出日涨幅作为唯一监督信号；
- 端点标签和报告继续保留为经济诊断基准；
- GBRT 保持 v0.1 已冻结的默认研究模型，固定因子与 Elastic Net 继续作为监控基线；
- 下一门槛是 DSR/多重尝试审计和未参与本轮的前瞻纸面交易。
