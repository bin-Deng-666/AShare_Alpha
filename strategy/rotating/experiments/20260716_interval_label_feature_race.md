# 2026-07-16 区间标签与特征工程赛马

## 预注册边界

- 研究依据与候选定义：[`docs/research/interval_label_feature_engineering.md`](../../../docs/research/interval_label_feature_engineering.md)；
- 数据快照：公开 SimTradeData `data-cn-2026-05-26` 与仓库 PIT 目录；
- 选择区间：2021-01-01—2023-12-31；
- 封存区间：2024-01-01—2026-05-22，在开发期选择冻结后只运行一次；
- 模型、季度重训、三年训练窗、随机种子、组合、容量和成本参数均保持不变；
- 每个训练样本都要求 `label_available_date <= prediction_date`。开发期报告只评价 `label_available_date <= 2023-12-31` 的标签。

完整重建的 2018-01-02—2026-05-22 面板有 9,007,822 行，其中 8,979,061 行（99.68%）具有完整五日路径标签。完整路径标签没有缺失 `label_available_date` 或中性化排名；不完整路径没有以前向价格填充。

## 特征包比较

候选在原有特征上固定增加八项：五日隔夜缺口、十日收盘位置、二十日趋势 `R²`、二十日趋势残差、二十日下行波动、十日振幅、二十日价量相关和 5/20 日换手冲击。标签先固定为 `T+1 open -> T+6 open` 五日端点收益。

| GBRT 开发期 | 原特征 | 原特征 + 八项 | 变化 |
|---|---:|---:|---:|
| 历史费用年化 | -4.54% | -2.83% | +1.72pp |
| Sharpe | -0.290 | -0.179 | +0.111 |
| 最大回撤 | -27.78% | -26.43% | +1.35pp |
| 20bp 固定路径年化 | -2.97% | -1.76% | +1.22pp |
| 平均 Rank IC | 0.08553 | 0.08744 | +0.00191 |

候选在收益、Sharpe、回撤、成本压力和 Rank IC 上方向一致，因此八项特征进入默认输入 schema。

## 标签比较

两组均使用上述增强特征。端点标签是实际计划退出收益；路径标签是 `T+2 ... T+6` 五个开盘相对 `T+1 open` 的累计收益均值。两者都在 `T+6` 才可用于训练。

| GBRT 开发期 | 五日端点标签 | 五日路径均值标签 |
|---|---:|---:|
| 历史费用年化 | -2.83% | -1.94% |
| Sharpe | -0.179 | -0.122 |
| 最大回撤 | -26.43% | -25.04% |
| 20bp 固定路径年化 | **-1.76%** | -2.27% |
| 对实际端点收益的平均 Rank IC | **0.08744** | 0.08680 |
| 对模型训练标签的平均 Rank IC | **0.08744** | 0.07746 |

| 年度 | 端点收益 / Sharpe | 路径收益 / Sharpe | 路径是否双胜 |
|---|---:|---:|---:|
| 2021 | 5.25% / 0.403 | 6.46% / 0.469 | 是 |
| 2022 | -9.49% / -0.458 | -10.71% / -0.523 | 否 |
| 2023 | -3.47% / -0.199 | -0.97% / 0.045 | 是 |

路径标签通过“两年收益和 Sharpe 同时改善”及“回撤不恶化超过 2pp”，但没有通过预注册的“20bp 压力下仍领先”，而且训练标签 IC 更低。因此不使用封存期打破结果，保留五日端点区间标签；路径标签实现和两套报告留存，供以后独立实验复现。

## 冻结后的封存结果

冻结方案为“八项增强特征 + 五日端点区间标签 + 原 v0.1 GBRT 研究模型”。一次性封存结果为：历史费用年化 10.84%、Sharpe 0.781、最大回撤 -11.40%；20/40/80bp 固定路径年化 10.53%/10.38%/10.08%；平均 Rank IC 0.09123，正 IC 日占比 80.67%。沪深 300 同期年化 15.38%，策略仍未通过生产准入。

相较 v0.1，封存年化从 12.08% 降至 10.84%，但这只作为诚实的泛化报告，不用于撤销开发期选择或继续调参。下一次收益改进必须使用新的预注册开发方案，并以未参与本轮的前瞻纸面交易检验。

## 决策

- 采纳八项增强特征；
- 默认标签继续使用 `T+1 open -> T+6 open` 五日区间收益，而不是下一日涨幅；
- 不采纳五日路径均值标签；
- GBRT 保持 v0.1 已冻结的默认研究模型，固定因子和 Elastic Net 继续作为监控基线；
- 状态保持 `research_only_forward_validation_required`。
