# 2026-07-16 区间标签与特征工程赛马

## 预注册边界

- 研究依据与候选定义：[`interval_label_feature_engineering.md`](../../../docs/research/interval_label_feature_engineering.md)；
- 数据快照：公开 SimTradeData `data-cn-2026-05-26` 与仓库 PIT 目录；
- 选择区间：2021-01-01—2023-12-31；物理隔离面板的最大行情日和最大标签可用日均为 2023-12-29，晚于 2023-12-31 的行情或标签为 0；
- 封存区间：2024-01-01—2026-05-22，在开发期选择冻结后只运行一次；
- 模型、季度重训、三年训练窗、随机种子、组合、容量和成本参数保持不变；
- 两个标签使用同一组增强特征和同一组完整可执行路径样本，每个训练样本都要求 `label_available_date <= prediction_date`。

八项增强特征由用户要求和研究预注册直接固定进入两组候选，不再用额外特征赛马决定是否采纳。与 v0.1 的原特征结果只作为回归参考，不构成本轮第二个选择门槛。

## 标签与样本

- 端点标签：`T+6 open / T+1 open - 1`；
- 路径标签：`T+2 ... T+6` 五个开盘相对 `T+1 open` 的累计收益均值；
- `T+1` 必须可买，`T+2 ... T+6` 每个开盘必须可卖；停牌、T+1 一字涨停或路径日一字跌停会使两种标签同时缺失；普通非一字涨跌停开盘与回测引擎一样允许成交；
- 标签收益使用前复权开盘价，可执行性使用原始 OHLC 和原始涨跌停价，禁止跨价格口径比较；
- 不前向填充价格；两种标签均到 `T+6` 才可训练。

开发期有 1,751,687 个合格信号，其中 1,731,166 个具有完整可执行标签，完整率 98.83%。缺失率随流通市值五分位从小到大为 1.42%/1.34%/1.12%/1.05%/0.93%；缺失数最多的行业为 C39 电子设备制造（2,552）、I65 软件信息服务（1,539）、C27 医药制造（1,302）、C38 电气机械（1,261）和 C35 专用设备（1,173）。按全部开发面板观察的信号日状态分组，非 ST 可交易、ST 可交易、非 ST 停牌的标签缺失率分别为 1.22%、5.15%、99.999%；样本中没有 ST 停牌组合。正式模型只使用信号日非 ST 且可交易的合格行。

## 冻结后的封存结果

冻结方案为“八项增强特征 + 五日端点区间标签 + v0.1 GBRT 研究模型”。一次性封存结果为：历史费用年化 13.24%、Sharpe 0.991、最大回撤 -9.18%；20/40/80bp 固定路径年化 13.20%/13.05%/12.74%；端点 Rank IC 为 0.09125，HAC(4) t 为 10.62。沪深 300 同期年化 15.38%。

封存期 GBRT 的收益和 Sharpe 均高于固定因子及 Elastic Net，但年化收益仍低于沪深 300，开发期绝对收益也为负，DSR/多重尝试审计与前瞻纸面交易尚未完成。封存结果没有用于修改选择，状态仍为 `research_only_forward_validation_required`。

## 决策

- 八项增强特征按预注册固定进入默认输入 schema；
- 默认标签改为 T+1 到 T+6 的五日端点区间涨幅，不再使用下一日涨幅；
- 路径均值标签因开发期稳定性门槛失败而保留为已拒绝候选；
- GBRT 保持 v0.1 已冻结的默认研究模型，固定因子与 Elastic Net 继续作为监控基线；
- 下一门槛是 DSR/多重尝试审计和未参与本轮的前瞻纸面交易。
